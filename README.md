# 驾考背题宝典

仿驾考宝典的背题应用：Python (Flask) + SQLite + HTML/CSS 前端。

## 功能

- **顺序练习**：按题库顺序答题，自动记录进度，下次从断点继续
- **随机练习**：乱序刷题
- **模拟考试**：限时答题、自动评分（科目一 100 题 45 分钟/90 分及格，科目四 50 题 30 分钟/90 分及格，可在 `app.py` 的 `EXAM_RULES` 中修改）
- **错题本**：答错自动收录，重新做对自动移出，可一键清空
- **收藏夹**：答题时点 ☆ 收藏重要题目
- **数据统计**：今日答题量、正确率、各科目进度、历史考试成绩
- **Excel 导入**：在首页"导入题库"上传 `.xlsx` 文件，或命令行导入

## 题型

单选、多选、判断（判断题固定为 对/错 两个选项）

## 快速开始

```bash
cd jiakao
pip install -r requirements.txt

# 生成 Excel 题库模板（含 5 道示例题）
python make_template.py

# 导入题库（方式一：命令行）
python import_excel.py 题库模板.xlsx
# 加 --append 表示追加而不覆盖

# 启动（方式二：启动后直接在网页上"导入题库"按钮上传 Excel）
python app.py
```

浏览器打开 `http://127.0.0.1:5000`

## PC 上使用

直接运行 `python app.py`，或运行 `python main.py`（自动打开浏览器，与 APK 相同的入口）。

## 安卓安装包（APK）打包

项目已配置好打包所需文件（`main.py` WebView 壳 + `buildozer.spec`），APK 内置 Python 运行时，**完全离线运行**，无需网络和电脑配合。

### 方式一：GitHub Actions 云端打包（推荐，无需配置本地环境）

1. 注册 GitHub，新建仓库
2. 把 `jiakao` 文件夹推送到仓库（包含 `.github/workflows/build-apk.yml`）
3. Actions 页面自动开始打包（首次约 20~40 分钟），完成后在 Run 详情页 Artifacts 下载 `jiakao-apk`，里面就是 APK
4. 修改题库后重新 push，会自动重新打包

### 方式二：本地打包（需要 WSL 或 Linux）

Buildozer 只能在 Linux 下运行，Windows 用户需先安装 WSL：

```bash
# 在 WSL(Ubuntu) 中
sudo apt update && sudo apt install -y git zip unzip openjdk-17-jdk autoconf libtool pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev cmake libffi-dev libssl-dev python3-pip python3-venv
pip install buildozer cython==0.29.36
cd /mnt/c/Users/Z-325\ R5/CodeBuddy/20261108171123/jiakao
buildozer android debug          # 首次会下载 SDK/NDK，耗时较长
# 产物：bin/jiakaobaodian-1.0.0-arm64-v8a-debug.apk
```

### 安装到手机

把 APK 传到手机（微信/QQ/数据线均可），点击安装。若提示"未知来源"，在系统设置中允许安装即可。

### APK 内题库说明

- **打包前**：先在 PC 上 `python import_excel.py 题库.xlsx` 导入好题库，`data/jiakao.db` 会随 APK 一起打包（buildozer.spec 已配置包含 `.db`），装上即用
- **装好后再换题库**：把 Excel 文件命名为 `题库.xlsx`，通过数据线/微信传到手机，放入手机 **下载(Download)** 文件夹，打开 APP → 首页 →「从手机下载文件夹导入（安卓）」。若导入失败，请在系统设置中给 APP 授予存储权限

### 注意事项

- APK 体积约 60~100MB（内置 Python 运行时属正常现象）
- 修改版本号：编辑 `buildozer.spec` 中的 `version`
- 修改应用名称/包名：`title` / `package.name` / `package.domain`

## Excel 题库格式

| 科目 | 章节 | 题型 | 题目 | 选项A | 选项B | 选项C | 选项D | 选项E | 选项F | 答案 | 解析 |
|------|------|------|------|-------|-------|-------|-------|-------|-------|------|------|
| 科目一 | 第一章 | 单选 | 题干…… | 选项1 | 选项2 | 选项3 | 选项4 | | | A | 解析 |
| 科目一 | 第一章 | 判断 | 题干…… | 对 | 错 | | | | | B | 解析 |
| 科目一 | 第二章 | 多选 | 题干…… | 选项1 | 选项2 | 选项3 | 选项4 | | | ABD | 解析 |

- 题型填：单选 / 多选 / 判断
- 判断题只填 选项A=对、选项B=错，答案可填 A/B 或 对/错/正确/错误/√/×
- 多选答案写在一起，如 `ABD`
- 列顺序可打乱，按表头名称匹配；解析列可留空
- 重新导入会**覆盖**同名科目的旧题目

## 使用流程（v1.4）

1. **首页**：只显示科目列表，点击某个科目进入**模式选择页**
2. **模式选择页**（科目二级页）：
   - 📖 **顺序练习**：按录入顺序，答完一题立即持久化进度；全部答完后再次进入直接停在最后一题，点**重置进度**才重新开始
   - 🎲 **随机练习**：展开面板选择**题型**（综合/单选/多选/判断）+ **题数档位**（10/20/50/100 题），点档位立即开始；档位超过题库数时自动按全部题数，不持久化档位
   - 📕 **错题本学习**：每个科目独立的错题本，**按录入顺序**显示答案和解析对照学习；移出按钮位于题目上方，需二次确认
   - 📝 **错题本考试**：错题随机抽答，题型/档位选择同随机练习；**做对自动移出**，移出按钮位于题目上方，需二次确认
3. **答题过程**：
   - **点击选项即记录**：未确认就翻页，返回本题时还原所选选项；确认后才显示答案
   - 底部按钮**位置固定**（visibility 隐藏不移位）：第一题"上一题"不可见；最后一题随机/错题考试显示"**交卷**"，顺序练习答完后显示"**返回**"
   - 随机练习/错题本考试进度条下方有"**答题情况**"按钮：显示总题数，答对序号（绿）、答错序号（红）、已选未确认（黄）、未答（灰），点序号跳转对应题目
   - 综合模式中题目顺序为**判断 → 单选 → 多选**
4. **我的**：数据统计 + 各科目练习进度 + 两个入口（均有"← 返回"按钮）
   - **科目库管理**（二级页）：列表展示所有科目，**重命名/删除（均有二次确认）**；重命名不允许重名；删除科目时其错题记录一并删除
   - **导入新科目**（二级页）：填写名称后上传 Excel（.xlsx / .xls），整个文件成为一个新科目（PC 网页上传 / 手机调系统文件选择器）

## Excel 题库格式（v1.2）

已去掉"科目"和"章节"列，支持 **.xlsx 和 .xls** 两种格式：

| 题型 | 题目 | 选项A | 选项B | 选项C | 选项D | 选项E | 选项F | 答案 | 解析 |
|------|------|-------|-------|-------|-------|-------|-------|------|------|
| 单选 | 题干…… | 选项1 | 选项2 | 选项3 | 选项4 | | | A | 解析 |
| 判断 | 题干…… | 对 | 错 | | | | | B | 解析 |
| 多选 | 题干…… | 选项1 | 选项2 | 选项3 | 选项4 | | | ABD | 解析 |

- 题型填：单选 / 多选 / 判断；判断题只填 选项A=对、选项B=错，答案可填 A/B 或 对/错/√/×
- 多选答案写在一起，如 `ABD`；解析列可留空
- 一个 Excel = 一个科目；重复导入同名科目会清空旧题后重新导入
- 命令行导入：`python import_excel.py 题库.xlsx [科目名]`（科目名默认取文件名）
- 模拟考试规则按科目名称匹配（含"科目一"= 100 题 45 分钟等），可在 `app.py` 的 `EXAM_RULES` 修改

## 项目结构

```

├── app.py            # Flask 主程序（页面路由 + API）
├── database.py       # SQLite 数据库层（建表、增删改查、统计）
├── import_excel.py   # Excel 题库导入
├── make_template.py  # 生成题库模板.xlsx
├── requirements.txt  # 依赖
├── 题库模板.xlsx      # 导入模板示例
├── data/             # 数据库文件（自动生成）
├── templates/        # HTML 页面
│   ├── index.html    # 首页：科目列表 + 导入题库
│   ├── practice.html # 练习页（顺序/随机/错题/收藏共用）
│   ├── exam.html     # 模拟考试（计时、交卷、成绩单）
│   └── profile.html  # 我的：统计 + 考试记录
└── static/
    └── style.css     # 全局样式
```
